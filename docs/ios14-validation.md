# iOS14.8 测试版验收与回退

## 本轮变化
- iOS14及无法识别的 iOS 版本，在共享原生传输工厂创建 Cupertino 前回退 IO，避免 iOS15 taskDelegate API；不改 iOS15+原生路径。
- 修复阅读追踪闲置恢复后误计暂停时间，提交增量不超过剩余阅读累计上限。
- 网络设置新增「iOS 14 网络验证」与「刷帖负载诊断」。两套采集均默认关闭、只保存在内存、有数量上限；不记录 Cookie、Token、URL、帖子内容或用户标识。
- 保留原有 CF 并发合并、冷却、手动验证和视频初始化策略。未根据猜测修改 rush 上报间隔、强关视频或常驻CF。

## 安装
1. 从本仓库 Actions 的 `iOS 14 test IPA` 成功运行下载 `fluxdo-ios14-test-*` artifact，解压。
2. 核对 `SHA256SUMS.txt` 与 IPA；查看 `ipa-inspection.json` 的 `errors` 应为空。
3. 保留此前原版 IPA，通过巨魔尝试覆盖安装，不先卸载。应用标识沿用上游；不承诺任何安装方式下 Keychain/Cookie都能保留。先备份重要草稿，若出现要求清数据的提示请暂停。
4. 本包未签名、非 App Store 包，适用已有巨魔的测试设备。不要求苹果开发者证书。

## 基础测试
- iPhone 12 Pro / iOS14.8，切标准模式：列表、进入帖子、图片、回复加载、通知和前后台恢复正常；不出现 iOS15 API版本错误。
- 避免为测试反复退出账户/清 Cookie；保留原有账户，登录失效只按正常登录流程处理。
- 第一轮先使用已有稳定网络；小火箭开关、DoH开关、模式每次只改变一项。

## DoH 验收
1. 在应用原有 DoH 设置中添加并选择 `https://linuxdo.ddd.oaifree.com/query-dns`（固定前缀），开启 DoH。不要同时更改其他代理设置。
2. 网络设置 → 调试 → **iOS 14 网络验证**：确认 DoH开关、网关运行状态、代理启动失败状态。
3. 点「测试当前 DoH」：调用生产 Rust 解析实现，强制刷新 `linux.do`。成功仅证明解析器返回地址。
4. 打开「采集实际请求路由」，返回刷帖，再回来「刷新记录」。`gateway + io-ios14 + gatewayResolverMatched=true + HTTP状态` 表示请求交给使用当前解析器的本地网关并收到响应头；结合本配置的 DoH查询成功结果判断。配置应用中、固定服务器IP覆盖、解析器不匹配时不能据此认定使用了当前DoH。
5. `direct-or-rhttp` 不等于已经证明 DoH；`webview` 不等于走应用 DoH。iOS17以下现有接口不能把 WebView接入应用代理，因此登录/过盾/兼容请求可能使用系统网络。
6. `settingsVersion` 不同表示历史配置记录，切换配置后重新清空、测试。HTTP状态只代表响应头，不保证流式响应完整或业务成功；403不能算浏览成功。
7. 复制脱敏网络报告；测试结束关闭采集。开启但失败时应显示失败/未应用，不用系统DNS结果冒充成功。

## 发热与 CF 对照
- 不充电、固定亮度/网络/内容/时长；手机先恢复正常温度。严重发热、系统温度警告时立即停测。
- 网络设置 → 调试 → **刷帖负载诊断**：启用后依次测试纯文本帖、连续未读楼层、包含多个上传视频的帖子（先不点击播放），每组约5–10分钟。
- 每组记下起止电量、明显发热/卡顿情况、实际 CF弹出次数、过盾后能否正常继续浏览，并复制聚合报告。各组之间清空计数，不同时开多个高负载应用。
- 报告包含 timings发送/成功/错误/退避、MessageBus、CF真实验证轮次与结果、隐藏WebView和视频初始化/销毁尝试。计数不等于资源存活数或CPU占用。
- 不把“屏蔽弹窗但加载一直失败”当作过盾改善，也不把修改计时等同于降温已验证。
- 首轮反馈用于决定是否需要 rush节流、视频懒初始化或CF生命周期优化，一次只改证据命中的路径。

## 回退
- 本轮不更改账户数据结构、Bundle ID或最低系统目标，也不清 Cookie。
- 若无法正常使用，保留报告后通过巨魔尝试覆盖回原版；不要为了回退先卸载。覆盖失败或出现数据风险提示时先停止并反馈。
- Git中保留独立修复分支，网络、计时/诊断、CI分别提交；不强推 main，不发公共 Release。

## 检查边界
自动测试、静态分析、IPA的plist与Mach-O检查通过，只能证明对应代码/静态声明；真机安装、登录、CPU/热状态、DoH实际采用情况与CF频率必须在用户设备验证。无需升级iOS。
